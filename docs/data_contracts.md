# Data Contracts and Schemas

Dino ML establishes explicit schemas across data capture, model bundles, and visualizer payloads.

## 1. Gameplay CSV Schema

Generated by `driver.recorder` in `data/gameplay/*.csv`:

| Column | Type | Description |
| :--- | :--- | :--- |
| `obstacle1_x` | float | Horizontal distance to nearest obstacle (-1 if none) |
| `obstacle1_y` | float | Vertical coordinate of obstacle |
| `obstacle1_type` | string | Obstacle category (`cactusSmall`, `cactusLarge`, `pterodactyl`) |
| `obstacle1_size` | int | Cluster size count |
| `obstacle2_x` | float | Horizontal distance to secondary obstacle |
| `obstacle2_y` | float | Vertical coordinate of secondary obstacle |
| `obstacle2_type` | string | Secondary obstacle category |
| `obstacle2_size` | int | Secondary cluster count |
| `speed` | float | Current world scrolling velocity (6.0 to 13.0+) |
| `jumping` | int (0/1) | Dinosaur airborne status |
| `ducking` | int (0/1) | Dinosaur ducking status |
| `time_to_impact`| float | Engineered feature: `obstacle1_x / speed` (-1 if none) |
| `action` | string | Action label: `jump`, `duck`, or `none` |

## 2. Model Bundle Schema

Saved in `data/models/*.pkl` via `joblib`:

```json
{
  "model": "<fitted scikit-learn estimator>",
  "game_id": "dino",
  "model_type": "decision_tree | random_forest",
  "features": ["obstacle1_x", ..., "obstacle1_type_cactusSmall"],
  "numeric_features": ["obstacle1_x", "speed", "time_to_impact", ...],
  "type_features": ["obstacle1_type", "obstacle2_type"],
  "categories": { "obstacle1_type": [...] },
  "target": "action",
  "actions": ["duck", "jump", "none"]
}
```

```json
{
  "model_name": "gameplay_20261108_decision_tree",
  "model_type": "decision_tree",
  "n_estimators": 1,
  "recorded_at": "2026-11-08 12:00:00",
  "duration": 14.5,
  "total_steps": 420,
  "crashed": true,
  "forest": { "model_type": "...", "n_estimators": 1, "trees": [...] },
  "records": [
    {
      "step": 1,
      "time": 0.05,
      "speed": 6.0,
      "time_to_impact": 18.2,
      "action": "none",
      "path": [0, 2, 5],
      "steps": [...]
    }
  ]
}
```
